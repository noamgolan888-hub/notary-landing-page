# אתר עו״ד ונוטריון

דף נחיתה בעברית (RTL), רספונסיבי ונגיש, לנוטריון יחיד. כל מסלולי הפנייה מובילים לוואטסאפ ולטלפון.
הטקסטים כתובים בגוף ראשון יחיד ("אני", "אשמח", "אחזור אליכם") — לא בלשון משרד.

## הפעלה

אין צורך בהתקנה, ב-npm או בתהליך build. פשוט פותחים את הקובץ:

```bash
start index.html
```

הכול נמצא בקובץ `index.html` יחיד — מבנה, עיצוב (Tailwind דרך CDN, גרסה נעולה 3.4.16) ולוגיקה.

**החלפת מספר דורשת עדכון בשני מקומות**: בקבוע שבסקריפט ובקישורים שבגוף ה-HTML
(חיפוש והחלפה של `972552625128` ושל `055-262-5128` יטפל בכולם).

## מה צריך להחליף לפני עלייה לאוויר

כל מקום כזה מסומן בקוד בהערת `<!-- TODO: ... -->`:

- [ ] **השם המלא** — כרגע "עו״ד ונוטריון" בלבד (בהדר, בפוטר, בכותרת הדפדפן וב-JSON-LD).
      להחליף למשל ל"עו״ד ישראל ישראלי — נוטריון"
- [ ] **מספר רישיון הנוטריון** — לא מופיע כרגע באתר; מומלץ להוסיף בפוטר
- [ ] **טקסט האודות** — שלוש הפסקאות בסקשן "אודות" (כתובות בגוף ראשון, לשכתב לפי הרקע האמיתי)
- [ ] **כתובת** — כרגע "רחוב הדוגמה 1, תל אביב" (בסקשן צור קשר ובפוטר)
- [ ] **שעות פעילות** — כרגע א׳–ה׳ 09:00–18:00, ו׳ 09:00–13:00 (בשני אותם מקומות וב-JSON-LD)
- [ ] **כתובת האתר** — בתגי `canonical` ו-`og:image`
- [ ] **תמונת שיתוף** — `og-image.jpg` בגודל 1200×630 עבור תצוגה בוואטסאפ ובפייסבוק

מומלץ גם לוודא שנוסח **ההבהרה המשפטית** בפוטר מקובל עליך.

**הערה על נתונים מובנים**: ה-JSON-LD בתחתית הקובץ מכיל כרגע טלפון ושעות פעילות, אך **בלי כתובת** —
עדיף בלי כתובת מאשר עם כתובת שגויה שגוגל יאנדקס. יש שם הערת `_comment_address` עם המקום להוסיף
את הכתובת האמיתית.

**מה לא נכתב באתר בכוונה**: אין מספרי "לקוחות מרוצים", "שנות ניסיון" או סטטיסטיקות אחרות.
אלה נתונים שאי אפשר לאמת, ובאתר של נוטריון הם פוגעים באמינות יותר משהם תורמים.

## איך הטופס עובד

הטופס אינו נשלח לשרת — אין צד שרת לאתר. בלחיצה על "שליחת הפנייה בוואטסאפ":

1. מתבצעת ולידציה בצד הלקוח (שם מלא, מספר טלפון ישראלי תקין) עם הודעות שגיאה בעברית.
2. נבנית הודעת וואטסאפ מהשם, הטלפון, השירות שנבחר והפרטים הנוספים.
3. נפתחת שיחת וואטסאפ עם ההודעה מוכנה — הלקוח רק לוחץ "שלח".

**המשמעות**: פנייה נרשמת רק אם הלקוח אכן לוחץ שלח בוואטסאפ. אם בעתיד תרצו שכל
פנייה תגיע גם למייל ללא תלות בלקוח, צריך לחבר שירות טפסים (Formspree / Web3Forms)
או צד שרת קטן.

## נגישות

- ניווט מלא במקלדת, כולל תפריט הנייד (נסגר ב-Esc) והאקורדיון.
- מבנה סמנטי (`header`/`main`/`section`/`footer`), היררכיית כותרות תקינה ו-`aria-label` על כל קישור אייקון.
- כיבוד `prefers-reduced-motion` — אנימציות מבוטלות למשתמשים שביקשו זאת.
- קישור "דלג לתוכן הראשי" וסימוני פוקוס ברורים.
- אנימציית החשיפה בגלילה מוגנת בשלוש שכבות (IntersectionObserver, גיבוי מבוסס גלילה,
  וטיימר בטיחות של 6 שניות) כדי שתוכן לא יישאר מוסתר בדפדפנים מוטמעים כמו זה של וואטסאפ.

## העלאה לאוויר

מכיוון שמדובר בקבצים סטטיים, אפשר לגרור את התיקייה לכל שירות אחסון:
Netlify Drop, Vercel, GitHub Pages או כל אחסון אתרים רגיל.

**הערה על Tailwind**: הגרסה הנוכחית משתמשת ב-Play CDN, שמקמפל את העיצוב בדפדפן.
זה מצוין לדף בודד. אם בהמשך תרצו טעינה מהירה יותר, אפשר לעבור ל-Tailwind CLI
ולהחליף את תגית ה-CDN בקובץ CSS מקומפל — שינוי של שורה אחת ב-HTML.
